# Ani’Moi — prototype V1

Mini-application web mobile de publication humoristique animalière.

## Tester
Ouvrir `index.html` dans un navigateur moderne, ou publier son contenu via GitHub Pages (racine de la branche principale). Aucun build nécessaire.

## Inclus
- Profils pour toutes les espèces, races facultatives, personnalité, photo compressée
- Plusieurs animaux conservés localement dans le navigateur (localStorage)
- Anecdote, 7 tons et 4 rubriques (Pawbook, SAV, LinkedPaw, Potins de gamelle)
- Génération de textes **à partir de gabarits locaux, pas d'API IA**
- Retouche, copie, partage natif et carte PNG téléchargeable
- Démonstration initiale de Malicia, fox-terrier

## Limites et prochaines étapes
- Profils non synchronisés : effacer les données du navigateur les efface. Pas de partage de comptes entre appareils.
- Les photos restent sur l'appareil. Attention aux limites de stockage local.
- La V1 n'est **pas** encore un réseau social et n'inclut pas d'IA générative. Ne jamais placer une clé d'API d'IA dans le HTML/JS GitHub Pages.
- Future V2 : serveur proxy sécurisé avec plafond d'usage, vrai générateur IA, comptes et modération, base Firebase ou équivalent.
- Le nom Ani’Moi reste provisoire jusqu'à vérification des marques et domaines.
